# ResQNet

ResQNet is a Data Fusion platform designed to assist rescue teams during disaster response scenarios.

The system combines multiple digital signal sources such as:
- Cellular activity
- WiFi status
- Smart meters
- Wearables
- Structural building data

Using these sources, the platform calculates rescue priority zones and generates a real-time rescue intelligence map to help commanders focus search efforts where trapped survivors are most likely to be found.

Core capabilities:
- Data Fusion
- Rescue prioritization
- Real-time simulation
- 3D visualization
- Heatmaps and rescue zones
- Context-aware analysis
